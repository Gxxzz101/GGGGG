# AI File Organizer

一个面向普通用户的文件整理桌面软件 MVP，而不是一次性脚本。

## 核心流程

1. 选择需要整理的文件夹。
2. 软件扫描文件名、类型、大小、修改时间和少量文本预览。
3. AI 生成整理计划，包括建议分类、目标路径、置信度和原因。
4. 用户检查计划。
5. 用户确认后，软件才会移动文件。

## 运行

```bash
npm install
npm run dev
```

默认不需要 API Key，会使用本地规则生成整理建议。

如需启用 AI 分类：

```bash
OPENAI_API_KEY=your_key npm run dev
```

可选环境变量：

```bash
OPENAI_MODEL=gpt-5.2
```

## 安全策略

- 默认只预览整理计划，不直接修改文件。
- 执行前会再次确认。
- 遇到同名文件会自动追加编号，避免覆盖。
- 扫描文本文件时只读取前 4000 字符，避免把大文件完整发给 AI。
- 对未知或低置信度文件归入 `Review`，让用户手动检查。
